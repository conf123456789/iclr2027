# ICLR 2027 Anonymous Demo

Static demo page for audio (`.wav`) and images.

## Demo link (after GitHub Pages is on)

https://conf123456789.github.io/iclr2027/

## How to add media

1. Put files in:
   - `assets/audio/` — e.g. `ex1_input.wav`, `ex1_ours.wav`
   - `assets/images/` — e.g. `overview.png`
2. Edit `demos.json` so `src` paths match your filenames.
3. Commit and push to `main`.

## Enable GitHub Pages

1. Open https://github.com/conf123456789/iclr2027/settings/pages
2. **Source**: Deploy from a branch
3. Branch: `main` / `/ (root)` → Save
4. Wait 1–2 minutes, then open the link above.

Keep the site anonymous (no names, affiliations, or identifying links) for double-blind review.
